# Roket

Dünya'dan kalkıp Ay'a inen roket.

| | |
|---|---|
| Model | Claude Opus 5.5 |
| Ayar | high |
| Araç | Claude Code |
| Süre | 37 dk 48 sn |
| Yapım | Three.js kütüphanesi + yazı tipi |
| Dosyalar | HTML + 1 JS (`core.js`) |

## Prompt

```
Dünya'dan kalkan bir roket simulasyonu yap. Ay'a inişini görelim. Fizik kurallarına uygun ve 3D olacak. Tasarım sana ait, hayal gücü sende.
```

## Notlar

- Dosyada karakter kodlaması satırı yoktu; Türkçe harfler bazı tarayıcılarda bozuk görünmesin diye en başa `<meta charset="utf-8">` eklendi. Kodun geri kalanı modelin çıktısı.
